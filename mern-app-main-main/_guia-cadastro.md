# Guia de Cadastro — Phytografia (banco `phytografia`)

> Banco zerado (só usuários). Este guia reativa os **dicionários** (selects) e cadastra o **1º lote de 6 plantas** pela interface.
> Nenhuma imagem será anexada agora — entre depois pelo **Editar** (o card usa placeholder enquanto não houver foto).
> Os campos **NPK**, **Frequência** e **Adubação** (fertilizing) **não têm input no formulário atual** — deixe em branco; a orientação de adubo vai dentro do texto de *Manutenção*.

## Ordem de trabalho
1. Abrir `https://<seu-site>/createplant` (logado como ADM).
2. **Seção A** — em cada campo de seleção, clicar no botão **`+`** e adicionar os valores da lista (um a um). Cada valor uma única vez (se aparecer duplicado, remova pelo botão `×` do dropdown).
3. **Seção B** — preencher a ficha da planta tab por tab (os campos de seleção só vão oferecer os valores que você adicionou na Seção A). Salvar.
4. **Seção C** — verificação pós-cadastro.
